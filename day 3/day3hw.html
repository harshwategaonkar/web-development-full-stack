Web Development Terms

HTML
HyperText Markup Language used to create web pages.
CSS
Cascading Style Sheets used for styling web pages.
JavaScript
A scripting language used to add interactivity to websites.
URL
Uniform Resource Locator, the address of a web page.
Browser
Software used to access and view websites.
HTTP
HyperText Transfer Protocol used for communication on the web.
